# Spotlight OS MVP

This workspace contains a static MVP prototype for Spotlight Multimedia, Inc.

Open `index.html` in a browser to use the prototype. It includes:

- Management exception dashboard
- Client master database
- Project Master separated into For Pitch/Bidding, On-Going, and For Closure/Collection lanes
- Project 360 lifecycle pages with CEO/COO/Finance-only project ASF and savings visibility
- CE workbook versioning, addendum CE support, and approval workflow
- CRP upload model, fund release controls, liquidation audit, and reimbursement controls
- CE vs CRP vs liquidation reconciliation
- Billing, collection, AR aging, closure, post-audit, notifications, supplier intelligence, global search
- Embedded product architecture, schema, roles, state machines, page map, financial logic, and build plan
- Role-aware employee dashboards built from reusable widgets instead of separate dashboard apps
- Graphs where useful: pipeline value by stage, estimated vs actual margin, team workload, creative workload/status, event readiness, liquidation aging, AR aging, incidentals, and content mix
- Refined lead dashboards for CEO, COO, Accounts Lead, Accounts Manager/Executive, Creative Director, Art Director, Production Head, Event Manager/Officer, Procurement Officer, Finance Officer, and Finance & Compliance Assistant
- Architect view includes Role Dashboard Matrix, Widget Data Contracts, Role x Information Matrix, and recommended homepage layouts
- UI/UX Pro Max pass: command-center shell, morning pulse KPIs, stronger dashboard hierarchy, polished widgets, refined charts, cleaner tables, and responsive onsite-friendly layouts
- Dark theme with Montserrat typography
- CEO refinements: customizable top cards, year-on-year monthly revenue comparison, organization assignment visibility, and CRP / liquidation override approvals
- Customizable dashboard widget sizing per role: Compact, Default, Wide, Tall, and Full
- Project Master uses disclosure / accordion rows so vertical project lists stay compact until a user expands a record

All sample data is seeded in `app.js` and uses relational IDs to preserve the project-first operating model.
